# Формат spec.json (сценарий ролика)

Один файл JSON = один ролик. Пример целиком: `examples/passkey_en/spec.json`.

## Верхний уровень
| Поле | Что это |
|---|---|
| `name` | имя файла ролика латиницей, напр. `passkey_ru` |
| `nick` | ник на экране: `@nyrgun.ai` или `@aibusiness.tools8` |
| `illus` | пометка на экране: `иллюстрация` / `illustration` |
| `voice.voice_id` | RU: `3EuKHIEZbSzrHGNmdYsx` (Nikolay). EN: `axEk2oXmtSTD1egGzX8U` (Adam, Calm) |
| `voice.model` | `eleven_v3` |
| `voice.text` | полный текст озвучки (числа словами; ник словами, напр. «Нюргун точка эй-ай») |
| `stages` | 4–5 этапов для шапки, напр. `["ЛОВУШКА","КЛЮЧИ","АДРЕС","ФАКТЫ","ДЕЙСТВИЕ"]` |
| `hook` | `{"a":"ОДИН КОД ИЗ SMS","b":"= ПУСТОЙ СЧЁТ","out":"счёт@end+0.1"}` — крупный текст первых секунд |
| `source` | `{"text":"Источник: …","from":"якорь","to":"якорь"}` — строка источника внизу |
| `keywords` | начала слов, которые в субтитрах подсвечиваются жёлтым |
| `subs_fix` | замены слов в субтитрах: `{"Fido":"FIDO"}` |
| `scenes` | 6–8 сцен (станций камеры) |
| `cues` | (необязательно) доп. звуки: `[{"at":"якорь","fx":"bell"}]` |

## Якоря времени (главное правило)
Время везде задаётся **словами из текста озвучки**, а не секундами:
- `"courier"` — начало слова; `"bank officer"` — начало фразы
- `"minutes@end"` — конец слова
- `"courier-0.2"`, `"stay+0.3"` — сдвиг в секундах
- `"sms#2"` — второе появление слова в тексте
- можно и число секунд: `12.5`

Якорь должен **дословно** совпадать со словами озвучки (регистр и знаки не важны). Если слово встречается несколько раз — используй `#2`, `#3` или фразу из 2–3 слов.

## Сцена
```json
{ "stage": 0, "start": "here's how", "cam": {"d":13.5,"y":1.2,"ox":1.4,"ly":-0.2}, "objects": [ ... ] }
```
- `start` — якорь первого слова сцены (у первой сцены `0`)
- `stage` — номер этапа в шапке
- `cam` — необязательно: `d` дистанция (13–14.5), `ox` сдвиг камеры вбок (±1.6), `ly` куда смотрит по высоте

## Объекты (поля общие)
`type`, `at` (появление), `until` (исчезновение), `pos` `[x,y,z]`, `scale`, `color`, `fx` (звук: `click`, `chime`, `buzz`, `boom`, `thud`, `bell`, `none`), `riser` (секунд нарастающего звука ДО появления), `to` + `dur` + `arc` (полёт из `pos` в `to`).

**Координаты:** центр сцены `[0,0]`, x от −2.6 до 2.6, y от −4.2 до 3.9 (выше/ниже залезет под шапку или субтитры).

| type | Особые поля | Для чего |
|---|---|---|
| `label` | `text` (`\n` — перенос), `size` 0.2–0.45, `style`: `good` `bad` `info` `warn` `accent` `green` `purple` `stamp` `note` `mono`, `glow`, `fam:"JBM"`, `rot`, `minW` | подписи, плашки, карточки, штамп |
| `phone` | `screen.items`: `{"text","y","size","color","font":"mono"}`, `{"card":true,"y","h","color","text"}`, `{"circle":true,"y","r","color"}`; `shake:[якорь,якорь]` | телефон с экраном (экран 512×1024) |
| `timer` | `at` → `until` отсчёт 00:00 → `end` (напр. `"02:59"`) | счётчик времени |
| `bills` | `to`, `n`, `gap`, `dur`, `spread` | разлетающиеся деньги |
| `orb` | `shape`: `sphere` `octa` `box` | узлы схемы (люди, счета) |
| `link` | `to` | линия-связь между узлами |
| `packet` | `to`, `dur`, `vanish` | «данные» летят по связи |
| `key` | `color` | ключ (может лететь) |
| `face`, `fingerprint` | — | иконки биометрии |
| `rings` | `until` | волны звука/звонка |
| `shield` | `r`, `hit:[якорь,якорь]` | защитная сфера |
| `cage` | `w`, `h` | рамка «остаётся внутри» |
| `check`, `cross` | — | ✓ (звук chime) / ✕ (звук buzz) |
| `bar` | `h`, `grow`, `counter:{"to":3,"final":"3+","decimals":1}`, `unit` | растущий столбец с цифрой |

## Правила хорошего ролика
- 1 объект = 1 подпись; новые подписи заменяют старые (`until`).
- На каждую ключевую мысль озвучки — появление объекта ровно на этом слове.
- 3–8 объектов на сцену, не больше. Ничего не ставить в одну точку.
- Финальная сцена: плашки CTA по очереди + ник.
