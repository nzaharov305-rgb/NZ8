# Шаблон роликов @nyrgun.ai, стиль v2 (14.10.2026)
Светло-синий фон в тетрадную клетку, 3D-эффекты (CSS 3D: конверт, переворот карточек, монета, щит, календарь, кнопки), субтитры по словам, звуковые эффекты.
Формат 1080x1920, 30 fps, ник @nyrgun.ai внизу (y около 1575), субтитры y около 1330-1480.

Порядок: сценарий -> озвучка (ElevenLabs, Nikolay, eleven_v3) -> транскрипция scribe (0 кредитов, слова с таймингом) -> правка RAW и сцен в index.html
-> make_sfx.py -> render.py full 2 (Playwright, jpeg) -> ffmpeg (atempo, loudnorm -14, amix sfx, libx264 crf 24).
В финале озвучки называть ник: «Нюргун точка эй-ай».
Эталонный ролик: ../ai_cybersecurity_phishing_45s_v2.mp4
